# Mancala AI Engine

A Python-based Mancala game and AI engine developed for CSC384: Introduction to Artificial Intelligence at the University of Toronto. The project explores adversarial search by implementing computer players that choose moves using Minimax and Alpha-Beta pruning.

The engine supports basic and depth-limited search, heuristic board evaluation, move ordering, and caching/transposition-table optimizations to improve search efficiency. It also includes a random agent for comparison, along with both command-line and graphical interfaces for playing and testing Mancala games.
